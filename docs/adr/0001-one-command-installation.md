# 一条命令完成安装与 Herdr 接入

现有安装流程要求用户编译程序、定位 Codex、手动合并配置并重载 Herdr，使用步骤过多。提供一条命令下载并安装预编译程序，自动定位 Codex、备份并合并 Herdr 配置、重载生效，同时展示修改结果；提供一条命令卸载程序并移除对应配置。该方式让已有 Herdr 和已登录 Codex 的用户直接看到额度，本地开发与维护操作使用 just 管理。

首版预编译包覆盖 macOS ARM64 和 Linux x86_64。安装命令支持首次安装、重试和更新，重复执行时补齐剩余步骤并避免重复配置。缺少前置条件时提供修复指引，用户修复后重跑同一条命令。

自动配置保留现有 tab 栏位置和其他状态项，只调整显示额度必需的设置，包括单 tab 时显示 tab 栏。
